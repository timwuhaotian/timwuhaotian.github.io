Kiled

A native macOS code editor that opens in a blink.

Kiled is a native macOS code editor written in Rust on GPUI and tree-sitter — Kil's sibling. It edits code and does nothing else: no terminal, no extensions, no git panel. It opens in a blink, uses no CPU while you think, and has VS Code's keys, so your fingers already know it. One binary and its icon: 4.8 MB to download, 13.5 MB installed.

Highlights

It edits code and does nothing else.

No terminal, no extensions, no git panel — a small editor that starts instantly and stays out of the way. Status: early, and tested on macOS 27.

VS Code's keys

⌘P, ⇧⌘P, ⌘D, ⌥↑↓, ⇧⌥↓, ⌘/, ⌘L, ⇧⌘K, ⌃G, F12, F8, ⇧⌥F, ⌘K ⌘W and the rest are where you expect them — and every one can be rebound, in the app or in ~/.config/kiled/keymap.toml.

Multiple cursors

⌘D, ⇧⌘L, ⌥⌘↑/↓ and ⌥-click. Every edit, copy and paste happens at each cursor, so a rename across a file is one keystroke sequence.

Syntax highlighting

Rust, TypeScript, TSX, JavaScript, JSX, JSON, YAML and TOML, incremental as you type and only for what is on screen. Anything else opens as plain text.

Language servers

Problems underlined as you type, completion, hover, go to definition (⌘-click or F12) and Format Document — via rust-analyzer, TypeScript 7's own server, vscode-json-language-server, yaml-language-server and taplo, whichever you have installed. Missing one? Kiled tells you how to install it.

Files handled safely

The explorer creates, renames (F2) and trashes (⌘⌫) — renames take their open tabs with them and nothing on disk is ever overwritten. Closing a tab, opening another folder or quitting asks first, saves are atomic and keep permissions, ACLs, extended attributes, symlinks and line endings, and binary files are never opened as text.

Idle means idle

No CPU at rest, and a keystroke costs a fraction of a millisecond even in a 50,000-line file. It also comes back with your folder, tabs, cursors and window where you left them — and checks for a new release at launch and every six hours, verifying checksum, Developer ID signature and notarization before installing it when you quit.

Get it

Download, drag, done.

macOS only: Apple silicon, macOS 14 or later. Language servers are found where your shell would find them and in a project's own node_modules — install the ones for the languages you use (rustup component add rust-analyzer, npm install -g typescript, npm install -g vscode-langservers-extracted, npm install -g yaml-language-server, brew install taplo).

Download

Grab the DMG, open it, and drag Kiled to Applications. It is signed with a Developer ID and notarized by Apple.

  • Kiled-arm64.dmg — 4.8 MB download
  • Installed — 13.5 MB, one binary and its icon
  • Requires — Apple silicon Mac, macOS 14+

Verify & update

The .sha256 ships in the same releases/ folder:

shasum -a 256 -c Kiled-arm64.dmg.sha256

Build from source

An Apple silicon Mac with Xcode's Metal toolchain (GPUI compiles its shaders at build time) and Rust 1.94 or later:

git clone https://github.com/timwuhaotian/kiled.git cd kiled cargo run -p kiled --release -- ~/code/my-project scripts/bundle.sh release # → target/release/Kiled.app
