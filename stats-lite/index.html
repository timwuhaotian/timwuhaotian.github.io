Menu bar · macOS app

stats-lite

CPU and disk usage in the macOS menu bar, and nothing else.

No settings, no charts, no dock icon: a cpu icon with the CPU %, an internaldrive icon with the used % of the boot volume. Numbers are monospaced and right-aligned, so neighbouring icons never bounce as values change. An idle machine costs nothing — CPU is sampled every 2 s (disk every 30 s), and the title is only rewritten when a number changes, so there are no WindowServer redraws at rest.

Highlights

Two numbers. Nothing else.

Most menu-bar monitors grow settings panels, graphs and background daemons. stats-lite stays at two readings — and spends nothing while your machine sits idle.

Two readings, one line

The menu-bar title reads e.g. cpu 12% · drive 34.2%: CPU usage and the used % of the boot volume (/System/Volumes/Data where it exists, / elsewhere).

Honest disk math

Purgeable space counts as used, and the number is the APFS container's used share — df's Avail column, while df's Capacity only counts the Data volume's own files.

One decimal, on purpose

1% of a disk is gigabytes, so a whole-percent number can sit unchanged for days. Disk shows one decimal: 34.2%, never 34%.

Nothing burned at idle

CPU is sampled every 2 s (disk every 30 s) and the title is rewritten only when a number changes, so there are no WindowServer redraws at rest. 1 s polling is what made Stats burn 59% CPU watching an idle machine.

No bouncing icons

Numbers are monospaced and right-aligned, so neighbouring menu-bar icons never shift as values change.

Signed, notarized, self-updating

Signed with a Developer ID and notarized by Apple. A new release is checked at launch and every six hours, downloads in the background, and installs when you quit — or right away with Restart to Update.

Get it

Download it, drag it, forget it.

Grab the DMG, open it and drag StatsLite to Applications. From then on it keeps itself up to date.

Download

Always the latest stats-lite, straight from the repo:

  • StatsLite-arm64.dmg — 662,505 bytes (about 647 KB)
  • macOS 14 or later · Apple silicon only
  • Version 0.2.5 — sha256 86e1738f…0338bd, published as releases/latest.toml
  • Install — open the DMG, drag StatsLite to Applications

Build from source

You need a Mac with Apple silicon and Rust 1.94 or later:

git clone https://github.com/timwuhaotian/stats-lite.git cd stats-lite cargo run --release

Bundle a StatsLite.app

For a StatsLite.app with its Info.plist, installed as a login item candidate:

scripts/bundle.sh release # → target/release/StatsLite.app ditto target/release/StatsLite.app /Applications/StatsLite.app
