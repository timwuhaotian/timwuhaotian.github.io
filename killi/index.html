killi

A tiny AI coding agent that fits in your terminal.

killi is a fast, tiny AI coding agent for your terminal, written in Rust: one small native binary, no runtime. Like Claude Code, Codex CLI, opencode or Kimi Code it reads your code, runs commands and edits files — but it works with any OpenAI-compatible, Anthropic-compatible or OpenAI Responses LLM. It is built around one idea: send the model as little as possible, the same way every time, so the provider's prompt cache keeps hitting. (Status: early. Apple silicon Macs only.)

Highlights

Seven megabytes, and it still does the job.

One native Rust binary with no runtime to install, a system prompt and tool list that never move so the prompt cache keeps hitting, and the agent features you actually use: MCP, subagents, swarms, plan mode, skills, hooks and AGENTS.md.

Small and quick

One 7 MB binary with no runtime to install. It starts in under 10 ms and uses about 18 MB of memory running a prompt — where Kimi Code uses 408 MB, Claude Code 318 MB and opencode 2 332 MB.

Few tokens

The system prompt and every tool together come to about 2,600 tokens, plus your AGENTS.md files and about 4 tokens per installed skill. In the capability tests killi passed every task Kimi Code passed, on the same model, with 5.6× fewer input tokens.

Cache-friendly by design

The system prompt and the tool list are fixed for the whole session, and history is only appended to, never rewritten. Plan mode, subagents and resumed sessions reuse the same cached prefix; 70–90% of input tokens come from the cache.

Stays out of the way

The conversation prints into your terminal's own scrollback; only a small area at the bottom redraws. Type / for a menu of commands and skills that narrows as you type, type while the agent works and your message reaches it at its next step. Esc interrupts — and nothing it started keeps running.

Plan mode, subagents, swarms

Shift+Tab blocks edits and runs only read-only commands until you approve the plan. Subagents run in parallel on the same cached prompt; swarms run one subagent per item of a template, up to 128, shown as one live panel. Background tasks keep servers and slow builds running.

Any compatible LLM

OpenAI-compatible, Anthropic-compatible or OpenAI Responses, plus MCP servers, skills, Claude Code-style hooks and AGENTS.md. killi login signs in with ChatGPT, OpenCode Go, Muse Code or Command Code. It is the sibling of the Kil terminal and the Kiled editor.

Get it

One command, ~7 MB.

The installer checks the binary's SHA-256 against releases/latest.toml and drops killi into ~/.local/bin. Apple silicon Macs only.

Install

The fastest way in:

curl -fsSL https://raw.githubusercontent.com/timwuhaotian/killi/main/install.sh | sh

What you get

  • macOS · Apple silicon — the only supported platform for now
  • killi-arm64 — 7.2 MB native binary, no runtime
  • ~/.local/bin — where the installer puts it
  • SHA-256 checked — against releases/latest.toml

Update or build

Later releases install in place, checksum and all:

killi update

From source, with Rust 1.94 or later:

cargo install --path crates/killi
