Terminal · macOS app

Kil

A native macOS terminal whose jobs outlive the window.

A native macOS terminal written in Rust, built on GPUI (Metal rendering) and alacritty_terminal. Vertical tabs, animated split panes and shortcuts you can rebind — and when Kil quits or crashes, your jobs keep running: reopen it and every pane is back on its live process, with vim's unsaved buffer, the ssh connection and the half-finished build where you left them. macOS only for now: Apple silicon, macOS 14 or later.

★ 2 stars MIT macOS 14+ · Apple silicon Rust · GPUI · Metal

Highlights

Vertical tabs, split panes, jobs that don't die.

Kil owns every process, PID and file descriptor it creates — so a crash or a quit only detaches you from work that is still running.

Vertical tabs in a sidebar

A ring marks a tab with a running job, a dot one whose job finished while you weren't looking. Drag a tab to reorder it, double-click to rename it (IME works, Chinese included), and a new tab is named for its folder.

Animated split panes

Panes animate open and closed with the keys or the two buttons at the top right of the tab. A new pane opens where the pane it split is, they share the tab evenly, and the focused pane is the bright one with a thin accent border on all four sides.

Jobs outlive the window

A small session server (kil --server, the same binary) holds every pane's terminal. ⌘Q and closing the window only detach from it — and so does a crash. The next launch goes back on the same processes, with the full screen, scrollback and input modes.

Remote panes for Agent on Edge

Settings ▸ Agent on Edge shows a QR code that pairs an iPhone to the same session server through a TLS tunnel, so the panes on the phone are the panes on the desk. kil --remote does the same from a terminal, and the standalone kil-remote binary works without starting the server. No cloud service or third party is involved.

Notifications from programs

When a program posts one (OSC 9 or 777: killi, Claude Code and others do when a long job ends) and its tab isn't in view, macOS shows it — naming the job, tab and folder it came from — and the tab gets the dot. Clicking it brings Kil forward and goes to the pane that sent it.

Comes back after a restart, too

The layout, each pane's directory and the window frame are saved within 2 s of a change, and each pane's screen and scrollback every 30 s while it prints. An idle window doesn't wake: no CPU at rest, and a blinking cursor redraws only itself.

Get it

Download, drag, run.

The DMG in the repo's releases/ folder is always the latest Kil, signed with a Developer ID and notarized by Apple. From then on Kil keeps itself up to date and asks before it installs.

Download

Grab Kil-arm64.dmg, open it, and drag Kil to Applications:

  • Kil-arm64.dmg — v0.0.34, 5.7 MB
  • Platform — macOS 14 or later, Apple silicon
  • Installed size — 8.6 MB
  • Signing — Developer ID signed, notarized by Apple
  • Updates — checked at launch and every six hours, then it asks

Verify the download

releases/ also holds the DMG's .sha256 next to it:

shasum -a 256 -c Kil-arm64.dmg.sha256

Build from source

You need a Mac with Apple silicon, Xcode with its Metal toolchain (GPUI compiles shaders at build time) and Rust 1.94 or later:

git clone https://github.com/timwuhaotian/kil.git cd kil cargo run -p kil --release # run it straight from the build

For a Kil.app with its icon and Info.plist:

scripts/bundle.sh release # → target/release/Kil.app ditto target/release/Kil.app /Applications/Kil.app
