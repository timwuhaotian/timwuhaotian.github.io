Agent skills · MiniMax Token Plan

minimax-skills

Every MiniMax modality, one npx command.

An open-source collection of agent skills that puts the whole MiniMax Token Plan behind a single command: 文本生成 / text, 语音合成 / speech, 音乐生成 / music, 音乐翻唱 / cover, 歌词生成 / lyrics, 图像生成 / image, 图片理解 / image understanding, 网络搜索 / web search and 视频生成 / video. Install it with npx, then describe what you want in Claude Code, Cursor, Windsurf or opencode — the matching API is called automatically and the result is saved to ~/minimax-output/.

Highlights

Ask in plain language. The right API answers.

The toolkit is one bash script plus a SKILL.md your AI coding tool can trigger on its own — no manual commands, no per-modality setup.

One command, every modality

npx skills add timwuhaotian/minimax-skills installs the skills; text, speech, music, cover, lyrics, image, vision, search and video all become available at once.

Automatic intent routing

"生成图片", "合成语音", "TTS", "写首歌", "cover", "联网搜索" or "做视频" trigger minimax image, speech, music, cover, search, video and friends — the skill picks the command for you.

API key auto-discovery

The key is found in MINIMAX_API_KEY, the opencode config ~/.config/opencode/opencode.json, Claude Code's ~/.claude/settings.json, your ~/.zshrc / ~/.bashrc, or a .env file. If nothing matches, it asks and offers to save it.

Quota-aware

Every capability runs on the Token Plan daily quota. minimax usage writes usage records to usage.json, and quotas reset daily — so you can see what is left before spending it.

Output lands locally

Everything is written under ~/minimax-output/: text/, speech/, music/, image/, video/ plus usage.json. Override the folder with MINIMAX_OUTPUT_DIR.

Async video, handled

视频生成 is asynchronous: minimax video creates the task, minimax video-status polls it and minimax video-download fetches the file — result URLs live 24 hours, so download them.

Get it

Install once. Use everything.

A Unix shell (bash or zsh) and npx are all you need — the toolkit itself is a single shell script that calls the MiniMax APIs directly.

One-command install

Add the skills to your AI coding tool — Claude Code, Cursor, Windsurf, opencode:

npx skills add timwuhaotian/minimax-skills

Then just say it: 生成一张赛博朋克风格的城市夜景图 and the image API is called.

Manual install

Prefer to wire it up yourself? The key is optional — the script finds it on its own:

# 1. API Key (optional, auto-discovered) export MINIMAX_API_KEY="sk-cp-xxx" # 2. Put the script on your PATH ln -sf ~/.agents/skills/minimax-toolkit/scripts/minimax.sh ~/bin/minimax echo 'export PATH="$HOME/bin:$PATH"' >> ~/.zshrc source ~/.zshrc # 3. Test minimax help
