The Pair

Two AI agents cross-check each other's code.

A free, open-source desktop app that runs a read-only Mentor which plans and reviews, and an Executor which writes code and runs commands — so AI hallucinations get caught before they reach your codebase. Grab a coffee; come back to reviewed, cross-validated work. (Yes, The Pair was built by The Pair.)

★ 386 stars Apache-2.0 macOS · Windows · Linux Rust · Tauri 2 · React 19
Download → apps.timwuhaotian.dev →
Highlights

One agent writes. Another one checks.

A single model writing and reviewing its own code can miss its own mistakes. The Pair's Mentor independently reviews everything the Executor produces.

Dual-agent architecture

Separation of planning and execution: the Mentor plans, reviews and validates (read-only); the Executor writes code and runs commands.

Ten provider CLIs

opencode, Claude Code, Codex, Antigravity (Gemini), Kimi Code, Pi, Kiro, Aider, Grok Build and Muse Code — plus local models via Ollama. Mix and match freely.

Unified pair console

Conversation, timeline, terminal events and activity in one scrollable feed, with live status, stall detection and per-agent CPU & memory.

Git change tracking

Modified, added and deleted files with a click-through unified diff viewer. Pairs run in your directory or in an isolated git worktree.

Full automation mode

Agents work autonomously with workspace-scoped permissions; an optional iteration budget pauses the run into human review when it is reached.

Local orchestration

The app and agent coordination run locally on your machine; only model calls go to your selected provider — or nowhere, with Ollama.

Get it

Install in a minute.

Download the desktop app for your platform, or install the terminal edition. You need at least one AI provider CLI installed and signed in.

Desktop app

Grab the latest build from GitHub Releases:

  • macOS — the-pair-{version}.zip
  • Windows — the-pair-{version}-setup.exe
  • Linux — the-pair-{version}.AppImage.tar.gz

Terminal edition

Prefer the terminal? Pair Code is the CLI edition of The Pair, on npm:

npm install -g pair-code

From source

Tauri 2 + Rust + React 19 + TypeScript. Node.js 22.22+ and rustup required:

git clone https://github.com/timwuhaotian/the-pair.git cd the-pair npm install npm run build:mac # or build:win / build:linux
